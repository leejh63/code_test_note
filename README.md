## 문서 관리

각 문제 문서에는 다음을 기록한다.

```text
최초 작성일
마지막 수정일
수정 이력
```

`최초 작성일`은 유지하고, 수정할 때마다 `마지막 수정일`과 문서 하단의 `수정 이력`을 갱신한다.

문제 원문이나 참고 풀이 코드를 저장하는 것이 아니라,
**내 풀이 과정과 학습 내용을 기록하는 것**을 기본 원칙으로 한다.

자세한 규칙은 `PROJECT_GUIDELINES.md` 참고.
